# Автобусные маршруты Норильска

Проект собирает автобусные маршруты из данных OpenStreetMap и показывает их на карте.

## Как запустить

1. Откройте проект в PyCharm.
2. Запустите файл `main.py`.
3. После завершения откройте в браузере файл `output/results.html`.

## Что находится в папках

- `app` — основной код проекта.
- `data` — расписания и исходные данные OpenStreetMap.
- `output` — готовые отчёты, таблицы и карта маршрутов.
- `tests` — проверки работы программы.
- `archive/legacy_code` — старые версии кода. Для запуска проекта они не нужны.

## Что делает программа

Программа строит полные автобусные маршруты по данным OpenStreetMap.

Она сохраняет развороты и участки, по которым автобус проезжает несколько раз. Если части маршрута не соединены, программа не рисует между ними выдуманную дорогу.

В отчёте можно:

◉ посмотреть все 36 направлений;
◉ выбрать нужный маршрут;
◉ увидеть остановки и их названия;
◉ приблизить или отдалить карту;
◉ перемещаться по карте;
◉ посмотреть маршрут целиком.
